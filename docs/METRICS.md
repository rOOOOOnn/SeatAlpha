# 指标口径

所有信号只基于公开会员持仓排名，不代表交易所认定的“机构观点”。跨品种比较采用比例或截面标准化，绝对手数仅用于品种内部观察。

- **净持仓**：Top20 多头持仓之和减去 Top20 空头持仓之和。
- **净持仓强度**：净持仓 / (Top20 多头 + Top20 空头)，范围约为 `[-1, 1]`。
- **1D 净变化（全景页）**：优先使用交易所品种级 Top20 汇总的相邻真实交易日差值；历史只有一个点时，使用该日席位排名表中的多空增减净额。
- **5D/20D 净变化**：当前净持仓减去同一品种相应交易日前的净持仓。
- **席位一致性**：`(净加多席位数 - 净加空席位数) / 有方向席位数`。
- **四类席位口径**：对同一观察日期、品种和一个主力排名合约分别聚合外资、游资风格、机构型、散户代理席位；没有进入 Top20 的类别显示为零席位，不以其他类别数据填充。
- **分类净仓**：该类别多头持仓之和减去空头持仓之和；分类净变化为多头变化之和减去空头变化之和。
- **分类标准化信号**：`0.55 × 净仓/总持仓 + 0.30 × 净变化/总持仓 + 0.15 × 一致性`，随后在同类别品种横截面做 Z-score。
- **四类分歧**：计算四类席位两两之间的标准化信号距离；品种分歧度取所有两两距离的绝对值最大值。
- **核心三方共振**：按外资、机构型、散户代理三类标准化信号是否超过统一方向阈值输出强多共振、偏多共振、分歧、偏空共振或强空共振；游资风格作为独立观察维度，不改变核心三方状态。
- **各板块代表品种**：先按板块分组，再依次按四类分歧度、最强绝对信号、总持仓体量排序，每个板块默认保留前 2 个；可在页面调整为 1–5 个。
- **综合信号分（全景页）**：当前可用品种截面内 `0.5 × Z(净持仓强度) + 0.3 × Z(1D净变化) + 0.2 × Z(一致性)`。
- **背离分**：价格变化和 5D 净持仓变化方向相反时为正；数值由二者变化幅度共同决定。
- **过去一年方向胜率**：按公司 × 品种统计。每个有效交易日以该席位公开多头持仓减空头持仓的符号作为方向，分别比较品种历史主表中 5、10、20 个交易日后的结算价；净多后价格上涨或净空后价格下跌记为命中。综合方向胜率为三个期限全部有效观察的命中数除以观察数，页面同时展示各期限胜率、当前多头、当前空头与当前净仓。品种详情仅排名至少有 20 个有效信号日的席位，缺失日期和未走完的期限不补零；并列时依次按有效信号日、平均方向收益和席位名称排序。公开会员排名没有实际开平仓成交价，因此该指标不等于真实交易盈亏胜率。

主力合约按当日持仓量最大选取。换月期间合约变化可能造成序列跳变，界面会保留具体合约代码；后续做回测时应使用同合约序列或加入换月校正。

全景历史优先采用 `position_history` 中的品种跨合约 Top20 汇总，避免主力换月导致净仓曲线断裂。广期所仅返回合约明细时按品种加总；大商所备用源目前只有主力合约快照，页面会显示真实日期及滞后标记，不与演示序列拼接。
